## ⚖️ How we work

- **Deterministic first** — the kernel computes without model calls; tokens are spent only where they earn it
- **Human approval gate** — actions that need confirmation present a proposal and wait; the system never acts past its authority
- **Isolation per organization** — one company's data, memory and budget never cross into another's
- **Fail-closed** — unreadable config means empty config and a log line, never a panic or a fallback
- **Source code delivered** — keys, repo, documentation: the client leaves owning everything
